# townhall-thumbnails

Rendered YouTube thumbnails for the Prosper XO town hall re-uploads.

**Why this repo is public.** The images are embedded into ClickUp review tasks
so Courtney can see what she is approving. ClickUp renders a markdown image from
any publicly reachable URL, but `raw.githubusercontent.com` requires a token for
a private repo and ClickUp has no way to send one — so a private repo would show
nothing at all. This repo holds finished PNGs and nothing else: no source, no
licensed font files, no credentials, no catalog data. The town halls themselves
are already public on [Austin Tech Live](https://www.youtube.com/@austintechlive).

**These are drafts pending approval.** A thumbnail here has not necessarily been
signed off, and some name speakers whose lineup is still being confirmed. Do not
treat this repo as published Prosper XO artwork.

Generated by [`prosper-xo/townhall-pipeline`](https://github.com/prosper-xo/townhall-pipeline)
(private) — `python3 -m pipeline publish-thumbnails`. Files are overwritten in
place on re-render; the pipeline links to sha-pinned URLs so a cached CDN copy
can never stand in for a revision.
